# Aither Apps

Aither Apps is the iPhone-inspired home screen and desktop launcher for the Aither app collection.

## v5.0 — Desktop Edition

The new desktop edition is a **real desktop launcher**, not just a wider mobile webpage.

- Native Electron desktop launcher for Windows, macOS, and Linux
- Large-screen dashboard layout with sidebar navigation and app cards
- Dedicated native windows for connected Aither apps
- Keyboard-first app search with `Ctrl/Cmd + K`
- Quick access to Aither Dashboard / Account & Data
- Recent/favorites launcher views
- Open Last App workflow
- Secure Electron context-isolated preload bridge
- External links leave the app window instead of silently navigating the launcher
- Single-instance desktop behavior
- Keeps the existing iPhone-style web launcher intact for GitHub Pages and mobile

### Desktop development

```text
cd desktop
npm install
npm start
```

Build installers with:

```text
npm run dist
```

## Web launcher

The browser version remains an iPhone-inspired home screen with responsive 4-column mobile and 5-column desktop layouts, search, pages, dock, edit mode, app library, and GitHub Pages support.
